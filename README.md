📌 Overview

An AI-powered WhatsApp Chat Analyzer built with Python and Streamlit that transforms chat exports into meaningful insights like activity trends, emoji usage, and sentiment analysis.



 Features

* 📊 Message, word, media & link stats
* 📈 Activity timelines & heatmaps
* 😂 Emoji analysis (Pie Chart)
* 🔥 Most common words
* 🤖 Sentiment analysis
* 🔗 Top shared links
